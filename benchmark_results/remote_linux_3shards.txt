==================================================================
KEY FINDINGS
==================================================================

1. **Shard Scaling**: 3 shards achieve ~55% of 11-shard performance
   - This is reasonable given 3x fewer shards and cores

2. **Latency Advantage**: Linux server has BETTER pipeline=1 performance
   - 88k vs 68k ops/sec (+29% improvement)
   - Shows better latency characteristics

3. **Throughput Trade-off**: Local macOS excels at high pipeline
   - 11 shards provide better throughput for pipelined workloads
   - But Linux is competitive for latency-sensitive workloads

4. **Gemini's Architecture Works**: Share-Nothing scales predictably
   - Performance scales roughly linearly with shard count
   - But connection-based sharding still has flaws (see previous analysis)
